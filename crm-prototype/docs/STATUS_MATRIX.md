# Что работает: артефакт, локальный проект, планы

Состояние на 07.10.2026. «Работает» — реализовано и проверено тестами из `ACCEPTANCE.md` в соответствующей среде.
Это не означает готовность к эксплуатации.

## 1. Опубликованный веб-артефакт (браузер, без сервера)

Опубликованная страница содержит **предыдущую** версию интерфейса. Новая сборка (`npm run build:demo`) не публиковалась.

**Работает в браузере:** интерфейс и те же доменные правила (расчёт и его статусы, версии КП, противоречия источников,
передача в работу); данные в localStorage этого браузера; предпросмотр клиентского КП и пакета передачи; резервная копия
как текст и её импорт с проверкой.

**Не работает в артефакте:** авторизация (есть только переключатель демо-ролей); защита ставок, маржи и заметок сервером
(данные урезает код в том же браузере); защищённый журнал и файл базы; совместная работа; скачивание Word/PDF.

## 2. Локальный проект (Node.js + SQLite)

| Область | Работает | Ограничения |
|---|---|---|
| Идентификация | логин и пароль (scrypt), сессии в HttpOnly-cookie, лимит попыток входа | тестовые учётные записи; нет SSO/2FA, сброса пароля, управления пользователями из UI |
| Права | роль действия + назначение на возможность проверяются сервером на каждом API-действии; чужой ID → 404 | роли заданы в seed |
| Финансы | ставки, затраты, маржа, комиссия, замороженное правило удаляются из ответов API и журнала для PM без разрешения, специалиста, принимающего PM; в клиентские документы не попадают | видимость для PM включает владелец на конкретной возможности |
| Хранение | SQLite, миграции, неизменяемые журнал и снимки (триггеры БД) | вложенные сущности хранятся в JSON агрегата |
| Одновременные правки | версия записи → конфликт 409 без перезаписи; список чужих изменений; повтор своего действия на свежей версии | конфликт возникает на уровне всей карточки |
| Расчёт | данные заполнены / оценки проверены / экономика утверждена — раздельно; пустое ≠ 0; разовые и ежемесячные работы раздельно; комиссия за привлечение — выплата из выручки | ставки и нормативы — тестовые, не утверждены владельцем |
| Версии КП | утверждённая версия заморожена (работы, расчёт, правило комиссии); изменения — только новой версией с повторным согласованием; прежнее решение сохраняется | вариантов КП на выбор нет |
| Передача | договорённости берутся из принятой версии; проджект отмечает готовность и отклонения; приёмка PM и разрешение владельца — отдельные события | — |
| Источники | разбор по ключевым словам (не ИИ), импорт структурированного результата со сверкой цитаты, без дублей при повторе | правила узкие; оригиналы файлов не хранятся |
| Документы | Word: КП, пакет передачи, клиентский и внутренний аудит; PDF выжимки; комплект аудита сохраняется снимком | PDF требует системного шрифта с кириллицей |
| Резервные копии | ручной экспорт JSON, проверка, восстановление в отдельный файл, `restore-check` | нет автоматического расписания и шифрования |
