# Экспресс-аудит клиники (30–40 минут)

Задача — найти 3–5 конкретных, проверяемых проблем, которые стоят клинике записей. Не надо делать полный аудит: это повод для созвона. Полный разбор показываете на звонке.

Итог: одна страница. Сверху — 3 главные находки с оценкой «сколько записей это может стоить», ниже — остальное.

Позже аудит можно делать вместе с Claude: присылаете название клиники и сайт, получаете черновик по этому чек-листу.

---

## 1. Тайный покупатель в WhatsApp (10 минут, самое ценное)
- [ ] Написать как пациент: «Здравствуйте, сколько стоит {услуга}? Можно записаться на эту неделю?»
- [ ] Время первого ответа. Ориентир: до 5 минут в рабочее время — хорошо, больше часа — проблема.
- [ ] Спросили имя, предложили конкретное время, назвали цену или вилку?
- [ ] Был follow-up, если пациент замолчал?
- [ ] Ответили на русском, если клиника продаёт «русскоязычных врачей»?
- [ ] Повторить вне рабочего времени. Есть автоответ или бот?

## 2. Сайт (7 минут)
- [ ] Мобильная версия: кнопка WhatsApp или звонка видна сразу?
- [ ] Ссылка `wa.me` работает? Правильный формат — без «+», например `wa.me/97150...`
- [ ] Есть цены или вилки на ключевые услуги (импланты, виниры, ботокс, эпиляция)?
- [ ] Ссылки на Instagram, Google-отзывы и Telegram есть и рабочие?
- [ ] Языковые версии работают (EN / RU / AR)?
- [ ] Мусор: тестовые страницы, шаблонный текст, опечатки, чужие контакты. Пример из базы: на doctor-maier.com остались московский телефон-заглушка и `t.me/ВАШЕ_ИМЯ`.
- [ ] Скорость: [PageSpeed Insights](https://pagespeed.web.dev/), смотреть мобильный показатель.
- [ ] Стоит ли аналитика (GA4, Meta Pixel, GTM)? Проверить расширением Tag Assistant / Meta Pixel Helper.

## 3. Google-карточка / локальная выдача (5 минут)
- [ ] Рейтинг и число отзывов против 3 соседних конкурентов.
- [ ] Отвечают ли на отзывы, особенно на негативные?
- [ ] Фото, услуги, часы работы, ссылка на запись.
- [ ] Позиция по запросу «{услуга} {район}», например «dental implants Jumeirah».
- [ ] Для русскоязычных клиник: есть ли карточка в 2ГИС Дубай и Yango Maps?

## 4. Instagram и соответствие DHA (7 минут)
- [ ] Частота постов, доля Reels, есть ли лица врачей и реальные пациенты.
- [ ] В шапке: понятный оффер, кнопка WhatsApp, хайлайты с ценами и отзывами.
- [ ] **Стандарт DHA ST-21 (циркуляр от 17.08.2026):**
  - [ ] Нет запрещённых формулировок: «the best», «№1», «100%», «guaranteed», «no side effects», «instant results» и подобных.
  - [ ] Фото «до/после» без ретуши и с согласием пациента.
  - [ ] Титулы врачей совпадают с лицензией DHA (не «Dr.» у тех, у кого нет такого титула в лицензии).
  - [ ] В профиле указан номер рекламной лицензии.
  - [ ] Нет агрессивной рекламы рецептурных препаратов (например, Mounjaro и Ozempic для похудения).
  - ⚠️ Формулировки сверить с первоисточником DHA перед тем, как приводить их клиенту.
- [ ] Отвечают ли в директ (повторить тайного покупателя через Instagram).

## 5. Реклама (5 минут)
- [ ] [Meta Ad Library](https://www.facebook.com/ads/library/?country=AE): крутят ли рекламу, сколько креативов, как давно, куда ведут (WhatsApp / форма / сайт).
- [ ] [Google Ads Transparency Center](https://adstransparency.google.com/?region=AE): есть ли поисковая реклама.
- [ ] Конкуренты в той же нише и районе: кто активнее рекламируется.
- [ ] Для русскоязычного сегмента: есть ли реклама в Яндексе (поиск с российского аккаунта и VPN ОАЭ) и в Telegram-каналах для русских в Дубае.

## 6. Оценка потерь (для первой страницы)
Простая формула для созвона:

> Если клиника получает **N** обращений в месяц, а из-за медленного ответа и отсутствия follow-up теряет хотя бы **10–20%**, то при среднем чеке **{X} AED** это **N × 0.15 × конверсия в визит × X** в месяц.

Цифры N и X спрашивайте на созвоне. В аудите показывайте только логику расчёта, без выдуманных чисел.
